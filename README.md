# Portfolio.github.io

## 📖 Project Overview
 
This is a single-page responsive portfolio website created as part of the WEEK06 HCI lab assignment. The website showcases my education, professional experience, projects, skills and contact details. It is built using **HTML** and **CSS** only (no JavaScript).
 
- URL Link to website portfolio: https://alexistef.github.io/Portfolio.github.io/

## 🎯 Purpose
 
The goal of this project is to:
 
- Present myself in a professional way
- Practice responsive web design techniques
- Learn how to structure and style a webpage with semantic HTML and CSS Flexbox

## 👥 Target Audience
 
This portfolio is designed for:
 
- Potential employers or recruiters
- University admissions or academic supervisors (credit-transfer academic exchange)

## 🧱 Technologies Used
 
- HTML5 (semantic tags: `header`, `nav`, `main`, `section`, `article`, `figure`, `details`, `footer`)
- CSS3 (Flexbox, Box Model, CSS variables, Media Queries, Transitions)
- Google Fonts: **Playfair Display** (name and "Contact" title) and **Poppins** (all other texts)
 
## 📐 Layout & Sections
 
The website includes the following sections:
 
- **Header** – Name, "PORTFOLIO" title and a fixed navigation menu with smooth scrolling to each section
- **About Me** – Education and professional experience
- **Projects** – Three project cards with a hover effect and links to GitHub
- **Skills** – Four accordions by theme (Networks, Telecommunications, Programming, Systems) with illustrated skills
- **Contact (Footer)** – Email, LinkedIn and GitHub

## 📱 Responsiveness
 
 Responsive design is achieved using Flexbox with `flex-wrap` (columns and cards move to the next line when there is not enough space), relative units (`rem`, `%`) and one media query (`max-width: 768px`) for the header and the sizes of titles and spacing.
